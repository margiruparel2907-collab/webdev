## Student-Hub: Student Portal

## Project Description:
  StudentHub provides students with a centralized platform to access academic information such as attendance, timetable,
  fee details, certificates, and profile management.

## Features:
  Login
  Dashboard
  Menu
  Profile
  Attendance
  Time-Table
  Fees-Information
  Faculty-Feedback
  Subject-Information
  Certificates
  Leave-Information
  Edit-Profile
  About-Us
